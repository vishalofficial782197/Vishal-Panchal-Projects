# Circuit Diagram

This folder contains the circuit diagrams and electrical connection details of the EcoGrow smart greenhouse system.

## Main Hardware

The system consists of:

- Arduino UNO
- NodeMCU ESP8266
- ESP32-CAM
- DHT11
- MQ135
- Soil Moisture Sensor
- Water Level Sensor
- LDR
- Relay Modules
- Cooling Fan
- Exhaust Fan
- Water Pump
- Lamp

## Circuit Design

The Arduino UNO interfaces with the environmental sensors and controls the greenhouse actuators through relay modules.

The NodeMCU ESP8266 provides Wi-Fi connectivity for IoT data transmission.

The ESP32-CAM is used for visual monitoring of the greenhouse.
